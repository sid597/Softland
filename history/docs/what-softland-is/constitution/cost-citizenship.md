coverage-receipt), where coverage is one of: exhaustive |
bounded-with-frontier | refused-with-named-bound. Coverage composes: a
result that encloses children inherits the weakest child status; an error is
a refusal, never an empty success; packagers propagate, never recompute,
child coverage. A scope that exceeds the synchronous rung escalates to a
receipted background sweep; refusals are loud. Every rung is receipted.

demonstrably reproduce the lying map: a failed child read gets certified
complete by its enclosing result — the one place the falsification round

own docstrings state the want the error path betrayed: truncation is served,
never silently swallowed; one place answers "what am I not being shown."
