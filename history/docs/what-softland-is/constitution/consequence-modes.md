# Consequence modes

**Law.** Consequences propagate three ways, distinguished by the link that
carries them. *Recompute* rides reference — one address, many projections;
code does the work. *Staleness* rides derivation — directed basis edges; a
mind did the work once, so the system marks and a mind repairs; staleness
rides *direct* basis. *Re-examination* rides co-reference — symmetric:
co-reference identity is the unordered endpoint pair (the group);
per-asserter assertions are strength inputs within it; the re-examination
question and its affirmation pair attach to the group — one seam per
subject-pair. Movement is mechanical; agreement is semantic and filed.

System-filed debt is durable, addressable material: one genus, three
species, three closers, each with explicit who-closes custody. Commissions —
what the code lane owes — close only by release through the slow lane.
Stale-marks close by any mind's mend independently checked, or by loud
break. Re-examination questions close by strength-carrying re-affirmation
from any mind, or — when the ends truly disagree — by seam plus signed
decision, the one closure terminating at the human. Closers are acts: each
cites the question and the endpoint revisions it examined; the funnel
refuses a closure whose endpoints have moved — the question stays open or
reopens. And rollback replays the record, never the query: a rollback
replays the accepted per-member act record — the resolution names scope;
refused or unresolved members mint no inverse and remain audit evidence.

**Why it binds.** Silent regeneration of a mind's derivation is
coherence-preservation running at machine speed — the named pathology.
"Mend" is category-wrong for co-reference: neither end derives from the
other. A merged queue with one closure law would let a mend close like a
release (unchecked) or force releases through mend ceremony — same queue
surface, species differences preserved. A closure that doesn't cite
revisions can clear a question that is already stale again; a rollback that
re-runs the query reverts a different set than was meant; re-affirmation is
itself an act with an asserter and therefore a strength — a weak affirmer
closes weakly, inheriting the pricing arithmetic without any new law.
