# Softland history

Earlier implementation work, plans, reviews, experiments, research, and session
records live here. The archive preserves context that can help explain a choice,
revisit an assumption, or understand recorded evidence.

| Earlier location | Archive location |
|---|---|
| Historical work folders and reports from `docs/` | [docs/](docs/) |
| `OLD DOCS/` | [old-docs/](old-docs/) |

Begin ordinary work with [the current documentation](../docs/README.md) and the
relevant source maps. Consult the archive when a specific question needs it.
Historical labels such as "current", "binding", "approved", or "next" describe
the record's original context; they do not establish present requirements or
authorize work now. Archiving a record does not decide whether all of its ideas
are obsolete or all of its proposed work was completed.

Check implementation claims against current code. Retain useful reasoning with
its assumptions and evidence limits when carrying it into current explanations.
Surface differences from the intended system in conversation, rooted in
[carry-on](../docs/carry-on.md) and/or [the vision log](../vision/LOG.md).

Records retain their original wording and historical path references except for
navigation links and executable path references repaired during the move.
Some paths already referred to earlier layouts before archival; their presence
does not imply that the referenced file exists in this checkout.
