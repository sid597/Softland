# Store JVM checks

[Parent: store verification](../README.md).

This namespace root contains [store/](store/README.md): the proof of the act, the
proof of the gates' pure namespaces and the door's, the proof of the store's
module on a cluster, the proof of the door on a cluster, the two proofs of the
read path, one with no cluster and one on a cluster, the proof that runs the
store's gates again over its depots, and the measures of the read build and
of the gates. It owns no state.
