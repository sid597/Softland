Sid, 24 September 2026, after a session wrote chat rulings into memory:
"memory is only for long term, anything that would be useful for future not
coming days. for that we need better way to communicate:
src/proposal/frame*/... a file in there that is like progress."

**Why:** Memory is loaded into every session on this project, including
parallel ones. A compression of a mid-flow exploration written there steers
every other session before the thing has settled, which is the cached-image
hazard in the lens. The proposal folder is where the work is; a progress file
there is read on purpose, next to what it is about, and can be rewritten.

**How to apply:** Before writing memory, ask: will this still be true in
months? Standing stances, hard rules, how Sid works: yes. Where we are, what
was ruled this week, what is next: no; that goes in the live folder's
PROGRESS.md (Now rewritten on change, Log append-only). Never write memory
mid-flow without Sid's word. See [[project-store-offers-the-spectrum]] for
the kind of thing that does belong.
