The electric-native DIRECTION.md accreted three preambles in one session —
each of Sid's chat confusions got a bolted-on block (convergence paragraph,
product-language block, workshop-placement block) until he called it: "total
shit way to guide anything" (2026-08-13). The doc had become a defense
against past confusions instead of a guide for the next session.

**Why:** Additive repair preserves the author's argument history, not the
reader's path. Each block was individually correct; the sum buried the
simple picture. The board's own law generalizes: if a fresh session (or
Sid) can't orient from the file top-to-bottom in two minutes, the file is
broken.

**How to apply:** When a doc needs its second explanatory patch, STOP —
rewrite and integrate instead: the frame that finally worked in chat
becomes the doc's spine; every prior block is woven into one structure or
demoted to a pointer. Guides stay one–two screens; detail lives behind
pointers (receipts files, law sections, the LOG). Related:
[[feedback-preserve-sids-vocabulary]], [[fix-the-generator-not-the-instance]].
