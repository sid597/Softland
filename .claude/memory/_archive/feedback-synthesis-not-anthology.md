When Sid asks to "compile", "incorporate all", or combine multiple sources
into a deliverable, he wants **synthesis**: one text written in a single
authorial voice that takes the best framing, craft, and content from each
source and weaves them — the way "a truly intelligent being would use
different sources of text after comparing." He does NOT want an anthology,
comparison table, ranking, or verbatim archive in the deliverable.

**Why:** Code-ingestor compilation incident (2026-06-10). After an 8-run
comparison, Sid asked for "a compilation for the best way to incorporate all"
as HTML. First version was an experiment report — conditions, rankings,
meta-findings, attribution badges, verbatim appendix. Sid: "what you made is
like a comparison table... i was interested in it and i got to see that in
the chat log but i don't want that to be in the html... the html's purpose is
for me to make progress on my task on my goal. are you proud of it?" The
clarifying question I asked beforehand didn't help because BOTH options I
offered were anthology-shaped — the option space carried the misread.

**How to apply:**
- The deliverable serves the goal; the process story belongs in chat (he
  reads it there happily).
- Write the synthesis as one author: adopt the best *framing* as the
  document's spine, the best *craft* for its structure, the best *content*
  for its substance. Attribution compresses to a one-line footnote at most.
- If the process record has preservation value (e.g. it's the only copy of
  other models' verbatim answers), park it in a SEPARATE file with a single
  footnote pointer — fold, never sever — but keep it out of the deliverable.
- When scoping such a task with AskUserQuestion, make sure at least one
  option is the true synthesis; check the option space against his words,
  not against the previous artifact's shape.
