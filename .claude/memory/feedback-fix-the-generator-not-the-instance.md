Sid (2026-08-06, the image-atom ceremony): "my goal was purely to work on the
workflow thing and fix it — you just took the example and replied to
everything." The prior reply analyzed the instance and handed back a starter
prompt that restated the regime — leaving every generator file intact, so
the next session would have regenerated the ceremony (a prompt-carried rule
dies with the prompt).

**Why:** Process behavior is generated by boot surfaces — CLAUDE.md,
AGENTS.md, decisions.md, `.claude/skills/*`, `.agents/skills/*`. Sessions
also imitate the most recent closed package's artifacts, so unwritten
ceremony propagates even when no live file mandates it; the fix must both
write the new law and explicitly name the dead pattern as
never-to-be-imitated.

**How to apply:** When feedback is about HOW work happens, edit the
generating files in the same turn (the direct ask authorizes the writes),
then hand a starter that only points at the law. Related:
[[feedback-logistics-answers-are-artifacts]],
[[feedback-exploration-starters-direction-not-shape]].
