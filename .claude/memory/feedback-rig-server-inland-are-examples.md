The rig (`src/proposal/rig-2026-09-25/`), the server and Inland are **examples**.
A finding of theirs about what Rama forced (refusals as data, the seal before
the depot, the hybrid stamp) is evidence, cited as a finding. No form, no name,
no call shape and no default for an undecided question comes from their code.

**Why:** Sid, 27 Sept: the rig "was about testing out the protocol before we
build anything on it". 5 Oct: "the instance and server code are just like
examples. They should not be the one driving the implementation." 6 Oct, after
act.clj was found to be the rig's envelope renamed: "there is nothing that we
[are] taking rig as the gospel of truth, it's just an example." The drift
happened twice in one day through session-written prompts that made existing
code the tie-breaker ("the rig's choice stands"; "the 5 October list's answer")
and once through the rig's class words slipping into a builder's brief.

**How to apply:** when a question has no ruling, write it as open and put it to
Sid; never default to what the rig/server/Inland do. Grep a build for the rig's
vocabulary before calling it done. The store tree's own rule is in
`src-store/CLAUDE.md`; the root `CLAUDE.md` carries the same line. Related:
[[feedback-ask-before-deleting]], [[feedback-memory-long-term-only]].
