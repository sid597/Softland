2026-07-17, end of the three-day genesis marathon: Sid asked "what do I have
to do before I start using softland / do I start p3 p4?" then "when should I
start a new session? can I run softland now?" — two pushes at the handoff
level. Both answers explained (mechanics, options, process) instead of
producing the obvious artifact: "Softland runs today, but first light — the
goal — doesn't exist until I build it; next session finishes it; here is
your one-line starter prompt." He had to write the answer himself and name
the miss ("why is it so hard to get the intent").

**Why:** the literal question is an attractor ([[meta-failure-generators]]
G1); the governing intent (the just-ratified goal) was an Unknown Known —
obvious to Sid, never written down (Thariq's Fable unknowns matrix; Fable
guidance says the model runs the blindspot pass, not the user). Max effort
amplifies the miss: deep reasoning aimed at literal words produces thorough
answers to the wrong thing (/effort max's own description warns
"overthinking — use sparingly for the hardest tasks"). Marathon sessions
decay boot-law salience: the same questions at session start would likely
have been answered right — which is exactly why the board/fresh-session
system exists.

**How to apply:** when Sid asks what-do-I-do / when-do-I / can-I-X /
handoff questions: (1) one sentence of goal-level truth first; (2) the
paste-able artifact — a prompt, a command, ≤3 acts; if the deliverable can
be pasted, the paste IS the answer; (3) one screen, zero process narration.
A SECOND logistics push means the artifact is overdue — produce it, never
explain again. End every work block with a self-run blindspot pass: "what
does Sid need next, in paste-able form?" — and write it into the final
report unprompted (the board's SID'S MOVES section is this instinct).
