# The rig, the server and Inland are examples

The rig (`src/proposal/rig-2026-09-25/`), the server (`src/app/server/`) and
Inland (`src-inland/`) are examples. Sid: "the instance and server code are
just like examples. They should not be the one driving the implementation";
the rig "was about testing out the protocol before we build anything on it."
A finding of theirs (what Rama forced: refusals as data, the seal before the
depot, the stamp) is evidence, cited as a finding. When you design something
new, the store above all, no form, no name, no call shape and no default
comes from their code. Where only their code would answer a question, the
question is open: work it from the problem, and bring it to Sid if it is a
decision (`CLAUDE.md`, "Who decides what"). Existing code never answers it by
default.
