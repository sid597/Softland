**Current decision status lives in**  
`docs/current-mental-model/​decisions.md` – the *decision log* (the “BINDING” log).  
The file records each decision as **PROPOSED** until it is countersigned, after which it is marked **CLOSED**. The “Verdict log (append‑only)” section at the bottom of that file records the status of each decision and any later amendments.

**Current “now / current” work state lives in**  
`docs/sessions/​next‑prompt` (the *next‑prompt* file).  
This file holds the exact next‑step contract for the ongoing session – the work that is currently active, the value that clears the state, and the conditions under which the state can be considered finished. It is the single source of truth for the present work‑in‑progress.
