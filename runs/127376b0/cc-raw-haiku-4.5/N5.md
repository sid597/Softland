## The Gates (1-16)

The contract specifies **16 acceptance gates** that must all pass for the work package to be considered done:

1. **Bundle completeness** — all six layers returned; relation rows match R1 rows
2. **Address round-trip** — each result's address parses and re-invokes to an equal result
3. **Omissions honesty** — returned + omitted counts equal fixture totals per layer
4. **Two clocks** — back-dated relation appears in today's arrival window with correct claimed-ms
5. **Evidence anchors resolve** — md anchor (char-unit) and transcript anchor (byte-unit) both correct
6. **Disagreement preserved** — both asserters' stances are `:current`, badged, unmerged
7. **Supersession fold** — retracting one stance and asserting another shows only the latest in `:current`
8. **Attestation staleness** — re-asserting an existing relation bumps `last-attested-ms`
9. **Activity exactness** — each accepted transition adds exactly one R3 row
10. **Custody** — envelope actor ≠ payload asserter → both durably on decision + event + edge rows
11. **Conversation trail** — ordered by byte-offset; page cursor works
12. **View-spec resolution** — `:latest` reflects a spec-doc revision; pinned `:rev` keeps resolving to old params
13. **Text projection (style gate)** — fixture bundle renders with all markers, address header, asserter badges, ≤ 4,000 chars
14. **Read-only by construction** — `trail-view-module` declares no depots and no ETL topologies
15. **Registry regression** — unregistered kinds still rejected; three new kinds accepted
16. **Kernel regression** — pre-existing relation-kernel suite (165 assertions) passes unmodified

## Definition of Done

As stated in the CONTRACT (§ 12): **"Definition of done: CONTRACT §11 gates 1–16 green in one suite run, incl. gate 16 (pre-existing 165 assertions green)."**

The full test specification includes a **shared fixture** and detailed criteria for each gate (CONTRACT § 11, lines 2067-2128).
