The do-not-preclude ledger

Constraints on phase 1 so the read-only MVP cannot corner the write surface — or the face. Nothing here asks anything to be built. Items 13–15 were minted by Sid's review of v2.

  1. Element-grain addresses. Every rendered element carries a stable address a human can say in CLI speech and an agent can resolve — at the grain of the gesture's selection shapes.
  2. The face states its own address (query + params) — a screenshot is a resolvable pointer, not just pixels.
  3. Anchor shapes stay open: point · interval · prefix · suffix · cut · pair · set — nothing new may hardwire anchor = byte-range-in-one-source.
  4. Kind signatures guide, never gate; the untyped flag (select + sign, type deferred) stays legal.
  5. Dual identity durable and renderable — payload asserter + envelope actor both persist ("sid, by fable's hand").
  6. Two clocks on every mark: marks render claimed-time; a re-imported old mark never looks fresh.
  7. No single-verdict-per-span rule anywhere; contradicting marks co-render, badged, unmerged.
  8. Thread-heads mintable by one assertion, including retroactively — a fork is one event, never an ingest ceremony.
  9. Retraction scars, never erases — both dates readable, in place.
  10. Mark-rows structurally distinct from terrain-rows in View 3's format — assertions unconfusable with material at the token level.
  11. Proposed ≠ signed reserved in the render grammar from the first face.
  12. No shadow log: previews are ephemeral view-state; a draft that must survive a session enters the kernel as a proposal row.
  13. Altitude text forms are data.new · Sid Every node/bundle carries title · decision/2-liner · full body, so semantic zoom reads from the contract — never from truncating whatever text happens to exist.
  14. No face may assume expansion-in-flow.new · Sid Opening detail must be able to cost local space only, with the trail persistent on screen — the data contract must not bake in outliner-reflow assumptions (e.g. detail only as nested children).
  15. Layout deterministic from the log.new · Sid x = time (given), y = lane (stable, derived); never force-directed, never reshuffling — spatial memory only binds to ground that holds still.
  16. Marks aggregate at every altitude.new · scale test The zoom functor carries mark / dead / question / new-since counts into every fold-chip; no altitude may hide that marks exist below it — and no fold may drop the ? count.
  17. The walk replaces the inbox.new · scale test “What's new” is a place-ordered diff from a walk-cursor, judged in place while walking — the contract must keep walk/attestation rows assertable (CLI/agent in phase 1) and must never require an arrival-ordered queue surface.
  18. Thread grouping is asserted structure.new · scale test Lanes fold on part-of–style edges so folding is lawful projection; ungrouped threads render as a visible band — never auto-filed, never hidden.
  19. Proposal caps are per-place, per-altitude.new · scale test Machine proposals render ranked and capped at the places they are about; no global proposal queue may ever be the answer to “where are they?”.
  20. Unwalked newness never escalates.new · walk “New since your walk” renders as in-place chips at every altitude, forever; no surface may nag, pulse, or re-order the land by unreadness. Suppression, not decay; abandoning a walk is a legal state.
  21. Walks are material.new · walk A walk is an addressable trail (its steps, its signs); step-attestations are assertable rows — but rendering must never REQUIRE walk data to exist (walkless readers still get an honest land), and ambient reading outside walk-mode must never write.
  22. A version is a cut, never a container.new · version Version rows carry target cut (point or point-set), statement, optional name, asserter, claimed-time — no locks, no copies; bedrock by address. Nothing may model versions as boxes that "hold" content.
  23. Version statements are altitude text.new · version Fold-level rendering prefers the latest human version statement; machine strata fill gaps wearing their badge, calibration bounded by sources. Signing cuts is what makes your own land legible from far away — the incentive is the altitude itself.
  24. Names graduate.new · version Versions are date-born; names optional at mint and conferrable later by use (speech-observed proposals, ranked, capped, one-gesture ratify) — the contract keeps the name field open, never required.
  25. No altitude without a landmark; emptiness is fog.new · terrain Every rendered region exposes at least one landmark (pennant, statement, pinned object) or renders as fog-of-war — a first-class state, never blank space. Data contract must supply per-region aggregates rich enough to honor this.
  26. The rim is closed and constant.new · terrain Scope · delta · address · palette — identical shape on every face, the address always stating where you are. Nothing else may ever join the rim.
  27. Animate within a geometry; cut between regimes; label every cut.new · terrain Face contracts declare which zoom regime (ground / room / ladder) a transition stays in or crosses, so the renderer can honor this — the gutter sentence is content, not chrome.
