CONCEPT 5: THE "NOTEBOOK" (Literate Programming Narrative)
Rationale: A document that mixes prose (reasoning) and executable blocks (actions).

  # Task: Fix Login Bug

  ## 1. Investigation
  I started by looking at the logs.
  > `grep_search "Login failed"`
  Found 1 error in `auth.clj` line 55.

  ## 2. Hypothesis
  The password hash isn't matching because of the salt encoding.
  Let me check the `hashing` namespace.
  > `read_file "src/util/hash.clj"`

  ```clojure
  (defn hash-pw [pw] ...)
  ```

  **Observation**: It uses SHA-1. We should upgrade this to BCrypt while we are here.
  
  ## 3. Implementation
  > `edit "src/util/hash.clj"`
  Replaced SHA-1 with BCrypt.
