# Candidate — Make the Span Self-Hosting

**Status:** nominated, unranked. Nominated by Sid, 2026-08-15 (his
testimony: [vision/the-interface-question.md](vision/the-interface-question.md)).
Priority belongs to the reconciliation session's board; this file records
the nomination and the closeness map so ranking is cheap.

**The candidate.** Ingest `docs/what-softland-is/` into the land as
material; edge its clauses and parts to the code they govern; light it with
the staleness lens. Then "grokking the architecture" stops being hours of
markdown and becomes pointing and asking — the constitution as blocks you
walk, wearing honesty about what moved under it. It is the first milestone
whose user is Sid with a need he felt the day he declined to read the
files, and it tests **absorption** — the product's stated core problem —
where the earlier-nominated vertical slice (ink + workshop scope) tests
authoring.

**Why it is closer than it feels — four stages, statuses from the signed
record:**

1. *The folder as material — configuration-grade.* Text is the one closed
   native: files cut into addressable, revisioned blocks; the prose path
   grammar and the watcher/importer pattern exist; code already ingests as
   atoms (git-spine). Needed: point the existing ingest at this folder.
   Everything medium-blind arrives free the moment blocks exist — marks,
   edges, canvas placement, connectors, ask-at-a-block with a narrowed
   briefing.

2. *Edges to code — a small mechanical build, and the edge sources already
   exist.* The architecture files carry their receipts as `file:line`
   strings — machine-parsable. A receipt-parsing import distiller minting
   `:grounds` edges from clause-blocks to code atoms is the graph economy's
   first real producer, receipt-stratum, nearly mechanical (relation
   kernel, asserter-in-identity, and the autotag cascade as silver-sweep
   template all exist). Gold tethers by hand stay open to Sid, as in the
   seam demo.

3. *Walking it — existing surfaces carry the first loop.* Canvas placement
   + the connector router (durable edges expanded over visible
   occurrences) + drill as the crude jump + ask at block grain: all
   running. The full 2D/3D provenance walk (occurrence queries, summon,
   placements-as-substance) rides the signed contracts — later, not
   blocking.

4. *Staleness-lit — the first genuinely new build.* The staleness
   projection ("what moved under this, weighted by what stands on it") is
   ratified as the first coined lens; its selection index exists
   (`$$relations-by-target`), its computation is revision comparison. It
   may ship first as an ordinary code-lane projection — the coined-lens
   machinery (lens grammar + admission, the one named new code-floor
   checker) is required to author lenses *as data*, not to have this one —
   and migrate up the ratchet later. And note the recursion: `file:line`
   receipts rotting as code moves is not a defect here — it is exactly the
   staleness the lens exists to light.

**Honest shape:** stages 1–3 are days-to-a-week of configuration plus one
small distiller; stage 4 is the first real build (small, specced). A felt
first loop — point at a clause, see its code tethers, ask it, watch it
stale when the code moves — is weeks, not months. The fuller vision Sid
named (these files as the *type* with instances shown, 3D code trails)
rides the signed span's contracts and comes after.

**Closes by:** the reconciliation session ranking it against the board; a
contract session cuts it if ranked.
