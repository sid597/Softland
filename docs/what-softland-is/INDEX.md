# What Softland Is — Index

The ladder this folder holds: **vision** (why it exists, what it must feel
like) → **constitution** (invariants that filter every decision) →
**architecture** (named parts: duty, seams, existence status, open questions).
Contracts — the per-part build specs — do not live here; they live with their
areas under `docs/<area>/` and cite these files. One owner per fact; every
other file links.
