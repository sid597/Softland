## What P3 implements

### Honest registry surface

The registry declares exactly four matter verbs, all at version 0 with
continuation `#{:invoke}` and honest `:verb/extracted-from` provenance:

- `:matter/deviate`, `:matter/activate`, and `:matter/rollback` are
  `:durable-via-request`;
- `:matter/preview` is `:pure-projection`;
- deviate requires `#{:master-id :subject-uid}`;
- preview, activate, and rollback require `#{:master-id}`;
- there are no release chains.

All four are registry-bindable in grammar terms. No current site supplies the
required matter arguments: v2+ refuses structurally, while frozen v1 can
accept-then-no-op. The exact `:durable-via-request` pin now names both durable
lanes: settle and matter act.

### Named act lane, existing durable owners

The disclosed invocation route is:

```text
window.__portal
  → POST /api/matter-room/{deviate|activate|rollback}
  → matter_room.cljc pure parameter builders
  → existing P6 owners only
```

- instance deviate calls `material-truth/deviate!`;
- master deviate calls `facet-master/import-candidate!`;
- activate validates an `activation-event` then calls
  `facet-master/activate!`;
- rollback accepts only a currently served `:portal/recovery` offer, then
  calls the same `activate!` with `:activation/kind :rollback`.

Malformed candidate activation returns an error card and leaves the active
revision unchanged. A forged rollback target that is not a current recovery
offer is refused before the pointer owner is called.

Preview has no server function and no HTTP route. `__portal.preview` delegates
to `__bindings.preview`; `endPreview` restores the served base object through
the existing P6 client membrane.

### Master-anchored Ctrl+Enter briefing

`matter_room.cljc` now owns the finite room-id reverse table and the only
master-anchored narrowing shape. For a registered room, the conversation id is
the server authority and produces exactly:

```clojure
{:master-id <one-derived-master>
 :conversation-id <room-id>
 :narrowed? true}
```

Caller-supplied entity, wearer, master, and master-set coordinates are ignored.
Unknown conversations retain P8's addressed-block narrowing. The explicit
`portal-briefing` parameter map now forwards `:master-id`, so the anchor reaches
the actual portal rather than degrading into entity mode.

The briefing's former read-only sentence now names all four verbs and their
effect classes, in this source phase as required by T9.
