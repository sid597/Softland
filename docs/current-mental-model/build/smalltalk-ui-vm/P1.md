## What landed

### The anatomy material and interpreter cutover

- New `fm:anatomy` grammar 0 owns the closed primitive, presence, view, prop,
  stamp, definition, and one-level sub-anatomy vocabularies. Its validators
  accumulate teaching refusals with the offending path, actual value, and
  legal set.
- The seed describes every former `block-tree` part. Single and multi-stamp
  rows mint the same facet contribution provenance as the legacy renderer.
  Presence is compiled through grammar-0 `:each`; no executable form or
  per-component dispatch entered material data.
- The existing assembly interpreter compiles the worn anatomy once per
  `[master-id revision-id]` and applies changing block/view data without
  recompilation.
- `rebuild-block!` now derives one closed view-model and renders only through
  compile/apply. The legacy `block-tree` and its temporary comparison/export
  hands are deleted.
- The block's private `text-op`, greedy/hard-break-aware `wrap-lines`,
  `lines-offset`, and rendered-line law moved into the primitive vocabulary so
  rendering and machine-selection copy still share one implementation.

### Conditional engine widening forced by G5

`face_assembly.cljc` gained one generic optional apply-data convention:
an `:each` item may carry numeric `:assembly/sibling-rank`. Ranked siblings
reorder only within the positions already occupied by ranked siblings;
unranked siblings retain their exact slots, and the private marker is removed
before any primitive receives children.

Anatomy assigns those ranks only to live same-slot composition contributions.
The set of material `:part/order` slots is unchanged; the actual
`facet-material/compose` result decides which contribution occupies each slot.
This preserves both ordinary priority order and deterministic conflict order
without restoring a block-specific composer.

### Material lifecycle and continuity

- `fm:anatomy` joins the generic facet-master census and object-container
  bootstrap. `fm:threaded` keeps grammar 0 byte-stable and gains explicit
  grammar 1 for rail width/color and indent, installed by the existing
  `ensure-active-source!` migration artery with `core/now-ms`.
- No module, depot, PState, topology, HTTP route, import composer, or verb was
  added. The Rama and retro-lens disciplines kept this on the existing generic
  OC revision/pointer path and required product-readable active revision truth.
- The material watcher defers a substantive re-derive while a pointer gesture
  is pending/active, then flushes after terminal `pointer-up!`. Electric can
  value-reemit an otherwise equal material serve during typing; the preview
  membrane now rebases its base/overlay identity across that equal emission,
  while a substantive serve move still ends the stale preview. This was the
  reactive-master-driven W8 correction.
- Preview, activation, rollback, and rebuild preserve focus, confirmed text,
  caret, selection, and structural node identity. Preview remains a client
  membrane: the active server bytes and pointer do not move.

## Disclosed judgment calls and corrections

- Presence vocabulary includes `:focused-or-hover`, because the legacy
  attention box's actual predicate is `(or focused? hover?)` and the original
  fourteen-key census could not express it.
- Root char-grid provenance uses a keyword-keyed multi-stamp map; a single
  stamp row cannot carry header provenance/foldable, body, hit, positioned, and
  threaded contributions without losing exactness.
- Sub-anatomy is one compile-time expansion level; definitions may not recurse.
- The G5 engine widening is generic apply-time sibling ranking, not a
  block/component branch. Ranked contributions still occupy the same sorted
  material-order slots.
- Full legacy goldens carry a precomputed `:anatomy-view` alongside the complete
  legacy input census. This lets the `.cljc` post-invariant test the exact
  interpreter boundary without duplicating the client-only view derivation.
- The contract's restart line is read as page/Electric-client restart on an IPC
  rig, disclosed rather than upgraded into a false JVM durability claim.
- Electric value-equal material emissions are identity-changing. The initial
  preview implementation became unapplied during live typing; rebasing the
  preview membrane across equal render state was required before W8/G4 passed.
