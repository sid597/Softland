activate accepted? true · DEFAULT FLIPPED WITHOUT ANY REPORT? true`.

## HIGH-2 — a durable FAIL report is laundered to PASS by re-marking the same revision with a different instance set

(`facet_master.clj:240-244`); marker BYTES include

Probe (real runtime): `FAIL report accepted · activate#1 refused
[:studio-report/not-passing] · re-promote accepted, same rev ·

DEFAULT? true`. Why the banked tests miss it: the bank's own comment
states the invariant ("a failed report may not be rewritten into PASS")
and then obtains its PASS from a DIFFERENT candidate — asserted by
construction, never attacked on the instance-set axis. MEDIUM-1 (no
durable-existence check on instance ids) makes the re-mark free.
