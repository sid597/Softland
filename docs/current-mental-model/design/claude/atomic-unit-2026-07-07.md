## 1 · The break — and why it is lawful

The whole-land mockup (1,341 real nodes, three populations, real joins)
rendered exactly what the land can currently say. Sid's felt verdict, looking
at it: *"even if i had this information what will i even be able to use with
this? the granularity is just too big … this whole tripple (agent chat, md
and code file) gives me nothing."*

This is **form-break evidence, not imagined demand**. D-002's stated goal —
"seeing it makes sense of like a decision tree and build artifacts" — cannot
be met by ANY rendering of container-granularity data, because the meaning
(what was decided, what built on what, what died) is not IN that data at any
granularity of container. The gap is in the data contract and was discovered
through the view — the D-005 co-evolution loop executing exactly as designed:
the view renders now; its gaps order the data work. D-001's trigger fired the
only way it can: a used form broke against real evaluation.

## 2 · What Sid found, said back sharply

**The unit of work is not a container; it is a turn of the loop:**
ask → deliberation → artifact-delta → *"is this the thing that should go on
top of the existing world?"* (his L1, verbatim). One such turn is one
semantic unit. The artifact-delta is what it changed; the conversation span
is WHY it is believable; the acceptance is its verdict.

**The word he asked for** (*"the chat that lead to this artifact is proof —
or use a better word"*): **warrant**. "Proof" implies deduction; a warrant is
what entitles you to hold a claim — Toulmin's term, and precisely the E+D of
the Q→C→E→D→R→F protocol his note already gestures at ("maybe its a
discourse graph, of question, claims, hypothesis, bets"). The unit IS the
protocol's molecule, met in the wild.

**Page 2's law — lineage lives at the unit level.** At file granularity the
26-May cluster is a hairball even with perfect edges (the mockup's 612-edge
amber fan demonstrated this the same night, empirically). The dashed arrow
"work → work-dash" — the thing Sid actually cares about — only exists
BETWEEN UNITS. Cross-day based-on edges between file-sets are incoherent;
between units they are obvious.

**The git proof.** In the mockup, commits are the ONLY population that
threads — because git is the only tool in the stack that FORCES the
unit-gesture at write time: every commit must carry a statement (message)
and lineage (parents). Sessions and docs were never forced, so they are fog.
The generalization: **the commit-gesture for thought — give docs and
sessions what git gave code.** This is sitting-3 queue item 3, re-derived
independently by the founder from felt failure — the strongest ratification
a queued question can receive. It also retro-explains the wall: Sid's
physical panels ARE hand-minted semantic units (statement + refs + lineage
tape). The wall's material was never the thing to take (taste #17); its
GRANULARITY was.

## 3 · Why it felt unwritable — the overdetermination diagnosis

Sid: *"whatever i write about this process it is never enough."* The concept
is not confused; it is **overdetermined** — one noun doing five jobs, so any
single description leaks the other four:

1. **The band-2 semantic line** (render): the authored/harvested one-liner
   R5 reserved space for (ledger 13's middle form).
2. **The write gesture** (2026-07-04 ruling, unchanged): mint / relate /
   verdict, one event shape — the unit is what that gesture mints.
3. **Agent context assembly** (LOG 2026-07-05: *"I don't have to be hunter
   and gatherer of context"*): the unit — statement + delta + warrant — is
   the retrieval key that lets an agent self-serve exactly the right spans.
4. **The behind-the-scenes distillation model** (LOG 2026-07-05 notebook):
   its output type was undefined; it is proposed units.
5. **The discourse graph made native** (Soul): Q→C→E→D→R→F stops being a
   future abstraction; the unit is its first living molecule.

Naming this dissolves the "never enough" spiral: each attempted writeup was
describing one facet and feeling the absence of the rest.

## 4 · The molecule — the floor against the regress [STANCE, strong]

A unit is **five fields, nothing more**:

| field | what it is | example (from this very sitting) |
|---|---|---|
| statement | one authored/harvested line | "Killed wall-emulation: the wall is provenance of questions, never material" |
| kind-lite | decide / claim / question / kill — folksonomy, grown by use (Law 5) | kill |
| delta | the artifact revision(s)/commit it landed | prompts doc v2→v3; taste.md #17 |
| warrant | the conversation span that deliberated it | Sid's "reality emulator" message → my repair |
| lineage | existing D-004 kinds, unchanged | supersedes v2 · based-on the fork map |

Verdict state rides the existing calibration machinery (proposed/ratified).
Every "what about X?" gets a standing answer: X is **evidence under a unit**,
or **a later unit kind**, or **a later stratum**. One unit type first
(taste #12). The boundary detector is the DELTA, not the message-turn: a
unit exists iff the world changed; deliberation-only stretches fold into the
next unit's warrant. [STANCE — Sid's L1 wavered between turn and artifact;
the artifact-delta boundary is the stable one.]

## 5 · What this promotes and demotes

- **Demoted:** container-level joins as VIEW nodes. Tonight's earlier "next
  moves" (promote the 612 commit→doc edges, session→doc path matcher) are
  re-scoped: those joins are how a HARVESTER finds a unit's delta and
  warrant, and how descent-to-source stays one gesture (taste #4) — inputs
  to minting and the honesty spine, never the trail's face.
- **Promoted:** the three populations become ROLES within a unit —
  deliberation (session span) · artifact (doc/code delta) · integration
  event (commit) — instead of peers on the trail.
- **Render mapping unchanged in grammar:** units are the terrain rows
  (R4–R7 hold: typography closed, surface open, lanes = lineage-connected
  units, kraft = relation marks); containers hang beneath a unit as band-3
  evidence. The band's meaning sharpens: unthreaded = material no unit has
  claimed yet. Every node is BORN WITH A TITLE (its statement) — the
  unlabeled-node problem ("updated electric" ×463) dissolves structurally.

## 7 · Falsification pass

1. *The graveyard attack — schema-first authoring cost killed Nupedia, Cyc,
   the Semantic Web.* Answer: this is publish-first, not gate-first — units
   land live as proposals; the harvest lane does the drafting; the forward
   lane rides discipline that already exists. Residual risk conceded:
   retro-harvest quality is unproven — hence the fixture-first test (§8),
   which costs a day, not an architecture.
2. *Message-turns are a noisy atom (retries, yes/no turns).* Held off by the
   delta-boundary rule (§4): no world-change, no unit.
3. *Does this reopen D-004 ("ontology: core sound")?* No. Edges are
   unchanged; this adds a node layer above containers. D-004 closed the
   edge noun; it did not foreclose future nouns; D-001's trigger has now
   fired for this one. Kernel change remains future-binding ⇒ Sid's hand
   (D-010); nothing in this doc builds anything.
4. *Regime-2 leakage?* No. Units are assertions OVER Regime-1 ingested
   material (address-don't-copy); no code-as-unit semantics; the
   self-hosting gate is untouched.
5. *Thousands of units re-create the hairball.* ~5–15 units/session ⇒
   ~3–7k over the corpus — within the fold/altitude rules already designed
   (R5/R7), and folding improves because every fold has a sayable line.
6. *Two truths drift (units vs containers).* Units carry evidence refs by
   address + content-hash — the drift-detection pattern already exists in
   the slice contracts.
