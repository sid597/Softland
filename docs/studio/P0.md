## 1. S1 — draft, promotion, durable report, guarded activation, reverse

### 1.1 Decision

Use **route (a): an ordinary durable block as the draft subject, wearing an
instance-scoped anatomy structure**. Its canonical structure identity is the
synthesized anatomy instance master
`fm:anatomy~i~<subject-digest>`. Behavior is material too: the same subject can
wear an instance binding row from the existing binding-bearing facet. A draft
is therefore a real canvas citizen plus real revisioned material, not a client
overlay masquerading as one.

registry or dynamic spec/read path. The registry is a source-level vector and
