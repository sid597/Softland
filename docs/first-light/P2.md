## Identity design (the load-bearing joint)

Episode conversation-id = the CLI session uuid, minted by US: turn 1 passes
`--session-id <id>`, later turns `--resume <id>` (no `--fork-session`, so id
and jsonl stay stable — verified: CLI 2.1.212 has `--fork-session` as the
opt-IN), and harvest derives conv-id from each jsonl line's own sessionId —
so native utterances and distilled agent material share ONE object-key, one
container, one face address. The genesis id is a fixed constant
(`episode/genesis-conversation-id`, A-scoped: the episode is a singleton by
design; B/worlds mint real ids); boot COMPUTES the address (the
default-address pattern) — birth-blankness = the container being empty,
never a state flag.
