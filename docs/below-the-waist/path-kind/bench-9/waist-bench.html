The cursor readout runs the filler's algorithm on the CPU at the cursor and reads the GPU pixel under it; they agree because both use the same curves and the same rule. It also shows what the two stroke constructions say about the distance to the drawn centerline.

  
Session 10 added the compositor and the executor. A clip is a second region whose coverage multiplies in the same draw; a blend reads a copy of the backdrop under the region; a layer is a surface painted as a region into its parent; a painting surface is retained at its declared resolution and advances per brush step. The definer's two records from attack 2 run verbatim: the pickup brush through a small executor on the GPU and on a CPU twin, the network through the geometry's arrangement. Fields of a record that no code read are listed under it.

  
Session 11 folded the definer's attack 3. A result is a value that keeps its contents: the executor's compile pass says where each binding is last read, and the GPU host paints in place only there, copying into a pooled target otherwise; every result carries the step that made it and its parent. A checkpoint is a construction continuation, saved with what it depends on and resumed on both hosts against the straight run. A mask on a group applies when the completed group is painted into its parent. Each fragment's local position now comes from its own pixel through the inverse map, which put the GPU and the CPU twin within float precision of each other.

  
Session 12 folded the definer's attack 4, a result used somewhere else. A clip's path may be a value a construction returned, frozen, or a live reference to a construction the record holds, which the executor resolves once per edit and the packer packs per scale. A record that returns a surface keeps it reachable: the executor's liveness follows values into the records and arrays that hold them, so a proof wrapped in a labelled record survives. A checkpoint can leave as bytes and come back into fresh hosts: an explicit wire with its dependencies, its continuation and each surface's content once, checked on load and refused with a reason when anything no longer holds.
