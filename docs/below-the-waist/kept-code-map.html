What the Waist Kept

The waist cut ruled on what to delete. This page draws what it kept — the shared material rows, the server, the parked render engine — one level below the editing-waist map's boxes: each area opened into its pieces (the server: each waist box into its file-groups), and for every piece what it is · what goes in · what comes out · why it is shaped so · who it talks to · its observed state. Arrows are drawn only where the code actually calls; islands are shown as islands. Sibling of the waist map, same system — that page's subject was what we cut; this one's is what we kept, so it can be judged by looking.

This page holds no verdicts. No box is approved or condemned; the question "is this how I want it architected?" stays open and is Sid's. Grain: one fixed level below the waist map for the surviving non-Rama code — every non-Rama waist box opened into its file-groups, with the arrows between them. The five deployed Rama modules (object-container · transcript-ops · relation-kernel · trail-view · face-arsenal) are not opened: they remain opaque terminal boxes at the waist-map grain, the floor non-Rama arrows terminate on. Not per-function (the three maps under docs/below-the-waist/ hold that grain), not a zoom ladder.
