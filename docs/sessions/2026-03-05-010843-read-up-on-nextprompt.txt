  State of Softland — Major Systems Overview

  1. WebGPU Editor Core — ~90% DONE

  The foundational layer. This is solid and mature.

  Done: MSDF text rendering, per-glyph theme colors (Zed-style), full editing
  (type/delete/cut/copy/paste/undo/redo), keyboard + mouse nav, bracket
  matching, code folding, SCI eval, settings panel, diagnostics HUD, idle CPU
  optimization (76% → 6%), pixel snapping, 4 monospace fonts.

  Remaining: Vim mode, structural editing (paredit), multi-file tabs, smooth
  scrolling, Ctrl+S writes to server (currently downloads).

  ---
  2. Reactive Architecture — DONE

  The "Great Refactor" (Session 8). Everything is m/latest compositions — no
  imperative update-then-render. Three core flows: <editor-rects,
  <combined-text-ops, <cmd-panel-rects. The missionary anti-patterns (m/ap +
  multiple m/?< = crash) are codified in CLAUDE.md as hard rules.

  ---
  3. Agent Runtime + Streaming — WORKING

  The pipe from UI to Claude CLI and back.

  Done: SSE streaming endpoint (/api/agent/stream), 8 canonical event kinds,
  stream parser, --resume via Rama session persistence, multi-provider toggle
  (Claude/Codex/Gemini), structured output (--json-schema).

  Not done: Tool-result events are parsed but not fully forwarded to client
  (:tool-result in trail but raw MCP data still dropped at server level).

  ---
  4. Rect Tree UI + Layout Engine — DONE

  The scene graph layer that replaced flat ad-hoc rendering.

  Done: rt-node data structure, tree->rects / tree->text-ops / tree->shadows
  walks, hit-test + dispatch-event with bubbling, drag state machine (IDLE →
  PENDING → DRAGGING), SDF rich quads (rounded corners, borders, gradients,
  per-corner radii), shadow pipeline (analytical Gaussian blur), layout engine
  (resolve-layout — CSS flexbox equivalent with
  direction/gap/padding/align/auto-height).

  ---
  5. Composable Component Library — DONE (the primitives)

  ui-card, ui-badge, ui-button, ui-divider, ui-progress, ui-scrollbar, ui-tabs,
  ui-tooltip, ui-panel, ui-panel-header/content/footer, ui-panel-group,
  ui-list-item, ui-checkbox, ui-priority-dot, build-empty-state.

  (typo-title/subtitle/body/caption). Surface elevation palette.

  6. WebGPU Sidebar — DONE (simplified)

  7. 3-Pane File Layout — DONE
