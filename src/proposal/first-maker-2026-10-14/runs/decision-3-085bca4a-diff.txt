+# Door — what arrives on a depot
+
+[Parent: store](../README.md) · [Store source entry](../../../README.md).
+
+This folder holds what the door and the gates must agree on: the form of a thing
+as it arrives on a depot, how a value is sealed to its place, and how a thing is
+given one text and one digest. The door itself is not built; the
+[module's proof](../../../../test-store/softland/store/README.md) plays it by
+hand. A gate checks each thing that arrives against this folder's declaration,
+and the gate is the authority: anything can append to a depot without the door.
+
+All of it is pure code and loads with Clojure alone.
+
+| File | Responsibility | State and lifetime |
+|---|---|---|
+| [declaration.clj](declaration.clj) | The door's declaration: what arrives on a depot, as shapes and rules in `act.clj`'s language; the store keys; the limits; the test for a stray; the check. | None. |
+| [seal.clj](seal.clj) | Locks and the seal: a lock's bytes, sealing a value to its place, opening it. | One random source for each process. |
+| [text.clj](text.clj) | The one text of a thing: one function from anything to a string, the same in every process. | None. |
+| [digest.clj](digest.clj) | The digest of a thing, SHA-256 over its one text. The door and the gates share it. | None. |
+
+## How the files relate
+
+[text.clj](text.clj) is at the bottom. It requires only [the act](../act.clj),
+for what a value is. [digest.clj](digest.clj) takes the digest of a thing over
+that text, and [seal.clj](seal.clj) binds a sealed value to the text of its
+place. [declaration.clj](declaration.clj) declares what arrives, and reads its
+shapes with the engine of [act.clj](../act.clj); it requires none of the other
+three.
+
+## Boundaries
+
+Nothing here reads the record. Whether a permission stands, whether a replaced
+fact is current and whether a lock opens a sealed value need rows of the record:
+those checks are [gate/](../gate/README.md)'s. Nothing here writes a lock
+anywhere: a gate writes a lock's row, in [module/](../module/README.md).

+# Gate — the decision, as pure code
+
+[Parent: store](../README.md) · [Store source entry](../../../README.md).
+
+This folder holds what a gate decides with: the checks of one act against rows
+of the record, the form of a layer's first act, the stamp, and the steps of one
+batch of the microbatch gate. It is pure code and loads with Clojure alone.
+
+No function here reads a PState, a clock or a random source. A gate reads the
+rows, calls these functions, and writes what they give. So the same checks serve
+both gates, each gives the same answer when Rama runs the work again, and each is
+proven without a cluster.
+
+The two gates themselves, the topologies that read and write the record, are in
+[module/](../module/README.md).
+
+| File | Responsibility | State and lifetime |
+|---|---|---|
+| [decision.clj](decision.clj) | The checks of one act against rows of the record, and the rows that a decision writes, as data. | None. It reads no PState. |
+| [first_act.clj](first_act.clj) | The class that a layer starts with, and the form of a making act. | None. |
+| [stamp.clj](stamp.clj) | The stamp: clock time and a counter in one integer, the next stamp, the 10-second rule. | None. It reads no clock. |
+| [batch.clj](batch.clj) | The pure code of one batch of the microbatch gate: what the depot derives from a thing, the turn of a thing, what an act asks of other tasks and what they reply, which acts meet, the decision of an act with its rows in hand, the home of each row. | None. It reads no PState. |
+
+## How the files relate
+
+[decision.clj](decision.clj) holds each check. It asks
+[first_act.clj](first_act.clj) whether an act has the form of a making act, and
+[stamp.clj](stamp.clj) for the stamp of a decision. [batch.clj](batch.clj) adds
+no check: it puts the things of a batch in one order and calls
+[decision.clj](decision.clj) on one act with all its rows in hand.
+
+## What it borrows
+

+# Module — what runs in Rama
+
+[Parent: store](../README.md) · [Store source entry](../../../README.md).
+
+This folder holds the topologies of the store's module: the two gates, and the
+three reads by which the door reads the module. Each file requires Rama.
+[module.clj](../module.clj), one folder up, declares the module `Store` and its
+two depots, and calls each of these files to add itself.
+
+| File | Responsibility | State and lifetime |
+|---|---|---|
+| [streaming_gate.clj](streaming_gate.clj) | The stream topology `streaming-gate` and the dataflow of one event. | It owns the four PStates of the streaming record, durable in the cluster. It borrows two PStates of the microbatch gate to read. Nothing in the memory of a process. |
+| [microbatch_gate.clj](microbatch_gate.clj) | The microbatch topology `microbatch-gate` and the dataflow of one batch, in four steps. | It owns the four PStates of the microbatch record, durable in the cluster. It borrows one PState of the streaming gate to read. Three temporary PStates of Rama live for one attempt of one batch. Nothing in the memory of a process. |
+| [door_reads.clj](door_reads.clj) | The three query topologies, for layers of both classes: the answer by act-id, the locks of a request, the class of a layer. | None. It borrows the two gates' PStates to read. |
+
+## How the files relate
+
+Each gate's dataflow only reads rows, calls pure functions and writes rows. The
+checks are [gate/](../gate/README.md)'s, the form of what arrived is
+[door/](../door/README.md)'s, and each row and each schema is
+[record/](../record/README.md)'s.
+
+Each gate reads one thing of the other gate's record: whether it holds a layer
+of which its own record holds nothing. The reads borrow both gates' PStates, and
+they write nothing.
+
+The walk of a thing through each gate, what the gates do not check, and the
+builders' choices are in [the store's map](../README.md).

+# Record — what the gates keep
+
+[Parent: store](../README.md) · [Store source entry](../../../README.md).
+
+This folder says what the record is made of: its rows, and the schemas of the
+PStates that hold them. It holds no record and it declares nothing. Each gate
+declares its own PStates with these schemas, because in Rama only the topology
+that owns a PState can write it. Those PStates are durable state of the cluster,
+and they are owned in [module/](../module/README.md).
+
+| File | Responsibility | State and lifetime |
+|---|---|---|
+| [rows.clj](rows.clj) | The record's rows: the text of each key, the making and the reading of each row, the routing id of an act-id, and the test of what a caller gave a read. Pure code; it loads with Clojure alone. | None. It holds no record. |
+| [tables.clj](tables.clj) | The record as PStates: the schemas, written once, and what each gate keeps for a task. It requires Rama. | None. It declares nothing. |
+
+## How the files relate
+
+[rows.clj](rows.clj) makes each row and reads each row. [tables.clj](tables.clj)
+gives the schemas, which take exactly the classes that those rows hold. A row of
+another class throws at the write, and a throw in a topology stops its
+partition; so a gate writes no row that [rows.clj](rows.clj) did not make.
+Neither file requires the other.
+
+## What it borrows
+
+A row's key is made of the printed texts of its ids, and a plain value is kept
+as the bytes of its one text. Both are [door/](../door/README.md)'s.
