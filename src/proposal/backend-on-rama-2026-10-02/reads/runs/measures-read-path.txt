The measures of the read build, as the build of read-path ran them once (12 October 2026): what the run printed, whole.
Command, from the repository root: clojure -M:store-module -m softland.store.read-measures
A run that is no proof. It holds nothing to a number. Rama 1.6.0, in-process, one machine, every row in memory, no network.

Two things about this run that the lines below do not say.
1. It was printed by the code as it stood before three later changes of the same build, none of which changes what a
   measure measures: the read's turn is named where it is taken (the same monitor); a read that is ended while it opens
   is not told {:ended}; and one binding of the measures file lost two names that it did not use.
2. The whole output of the run was 8792726 lines and about 1.0 GB, nearly all of it Rama's own log of openings of a push
   that it refused: 98794 lines hold "exceeds pstate.proxy.limit". One of them, cut:
   Caused by: clojure.lang.ExceptionInfo: Number of proxies on PStates exceeds pstate.proxy.limit dynamic option
   That raw file is beside this one, raw-rp-measures-full.txt. It is not committed by this build, and this build did not
   remove it: whether it is kept is for the build session or Sid to say. Every line that the measures themselves printed
   is below.
