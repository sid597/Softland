## Checked on 10 and 11 October — facts, not questions

- **Rama's push** (Rama's word: proxy). A program names a path to exactly one value in a table. Rama gives it, and then sends each change as a small diff. A push can watch a value inside a table. It cannot watch a table itself, nor a part of a table that keeps its elements apart. {{Rama docs: 15-pstates.md, lines 438 and 654}}
- **For a streaming table**, the work of a push is done with the write, on the gate's own thread, up to a time limit; and a reader can be left out of one change and is then sent the value anew. The docs say this of streaming tables only. {{15-pstates.md, line 1230}}
- **A push needs a table that a client may read.** A table that is declared private refuses every client. {{28-clj-defining-modules.md, line 263}}
- **Rama asks no name.** Any program that can open Rama's ports can use Rama's client to append to a log, read a table and call a query. Rama also has a REST API, on port 8888 and on each Supervisor, that does the same for what JSON can carry. The local docs name no login for either, and no setting that turns the REST API off. {{24-rest-api.md; 26-all-configs.md; a search of every page}}
- **The gate opens each value when it checks it**, and then keeps only the sealed bytes. The store's own facts, such as a permission, are kept plain. {{gate/decision.clj; record/rows.clj}}
- **As built, a store key takes one write for a place**, and a permission sits on its holder: a holder has one permission in a layer. {{gate/decision.clj; the store's page, src-store/softland/store/README.md}}
- **No speed of the built store is measured against its targets.** The one timing is the base's (W13). The figure of 480 to 770 acts a second on one task is arithmetic. {{store-module/PROGRESS.md}}
- **The Rama docs here are an extract of March 2026.** The project pins Rama 1.6.0. Nothing above was run on it for this sheet.
